# TOP-Project-Admin-Dashboard

This is a project assignment from The Odin Project, Intermediate CSS and HTML module, respectively
the its last section which revolves around grid manipulations and layout. The main objtective of this
project was to create a full admin dashboard mainly using a grid layout.
For this project I used a layout focus design that mainly used grid to create the main layout of the
dashboard; and I used flexbox complementary to align the inner content of the grid items. 
The SVG icons were obtained from the site https://opensvg.dev/icons
and https://pictogrammers.com/library/mdi/ respectively.
